# Inkstone Notes

Inkstone Notes is a note-oriented theme website based on secondary development of [jsw-teams/siteforge](https://github.com/jsw-teams/siteforge).

It focuses on technical notes, archives, categories, tags, search, privacy preferences, and static publishing. The theme also adapts footer display for China mainland compliance filing information, including ICP and public security registration records.

## Build

```bash
npm run build
```

The generated site is written to `dist/`.
